# React Post Create Feed

A simple full-stack web application built with **React.js, Node.js, Express.js, REST APIs, and MongoDB**.

The main focus of this project is learning how a React frontend communicates with a backend through REST APIs and how data is stored and managed using MongoDB.

## 🚀 Features

* Create posts
* View posts
* Manage post data through REST APIs
* React-based frontend
* Node.js + Express.js backend
* MongoDB database integration
* API-based communication between frontend and backend

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mayankrai2505/react-post-creat-feed.git
```

### 2. Install dependencies

Go to the backend folder:

```bash
cd Backend
npm install
```

Then install the frontend dependencies:

```bash
cd ../frontend
npm install
```

### 3. Environment Variables

Create a `.env` file inside the `Backend` folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

Do not upload your actual `.env` file or database credentials to GitHub.

### 4. Run the Backend

```bash
cd Backend
npm start
```

### 5. Run the Frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

## 🔌 API

The frontend communicates with the backend using REST APIs.

The backend handles requests related to creating and managing posts and uses MongoDB for data storage.
